# 北欧旅行计划

这是可直接上传到 GitHub Pages 的静态网站包。

## 文件结构

- `index.html`：网站入口
- `assets/photos/`：从 Google Maps 地点照片/收藏截图裁切的真实景点与地点封面照片，共 46 张本地 JPEG
- `assets/covers/`：旧版 SVG 资源，仅作为历史备份，当前页面不会优先使用
- `nordic_travel_planner_cn_v6_intake_fixed.html`：原文件名备份

地点卡片和详情抽屉优先使用 `assets/photos/` 中的真实封面照片；没有对应照片的地点显示中性占位。封面使用相对路径引用，不依赖外部图片服务。上传整个目录中的文件后，GitHub Pages 访问时会一并加载封面。

本次补充了 `intake-stockholm-city-hall.jpg`（斯德哥尔摩市政厅）和 `intake-stockholm-central.jpg`（Stockholm C），并在行程地点卡片中启用对应封面映射。

费用页新增“退税攻略”模块，按本次哥本哈根 → 奥斯陆 → 斯德哥尔摩 → 北京路线整理丹麦、瑞典集中办理、挪威火车离境风险、机场流程、7 项检查清单和官方信息入口。退税规则和柜台营业时间请在出发前以官方最新信息为准。

## GitHub Pages

将本目录中的全部文件上传到仓库根目录，然后在仓库的 **Settings → Pages** 中选择部署分支和根目录即可。

## 2026-09-26 基础修复

- 编辑地点保留预约状态、规划备注、评分等已有字段。
- 仅首次使用时填充预置收藏，刷新不再恢复已删除地点或重复添加改名地点；恢复示例功能仍可重置数据。
- 行程按时间排序，同一时间或未设时间时按手动顺序排列；跨时间调整需编辑地点时间。机场接驳补充为 15:30。
- 汇率必须是有限正数；读取旧的无效汇率时恢复默认值，费用金额也增加有限数字校验。
- 保存地点后先切换目标日期再更新页面。

通过 Node 隔离环境的逻辑回归检查，包括编辑字段保留、删除/改名后重新初始化、时间排序、汇率校验、重置和本地资源完整性。尚未进行真实浏览器视觉和移动端验证。

使用方法：用本包完整替换站点文件。相同域名下继续使用已有浏览器数据；旧版本已经丢失的字段无法自动恢复。当前仍只支持本地存储和 JSON 导出，不包含跨设备同步或导入恢复。
